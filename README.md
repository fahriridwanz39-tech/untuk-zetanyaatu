# 💕 Untuk Alzena Fausta Azalia

Website sederhana untuk mengungkapkan rasa sayang, cinta, dan kangen
kepada **Alzena Fausta Azalia** (Zeta).

## 🌸 Isi Website
- 💌 Amplop pembuka — klik untuk buka pesan
- 📸 Galeri foto polaroid
- 💖 Ucapan sayang, cinta, dan kangen
- 🎵 Musik romantis di background
- ✨ Animasi hati jatuh & efek klik
- 🔍 Klik foto untuk zoom
